SwimFlow 개인정보처리방침

시행일: 2026년 9월 18일 · 1.0.0(6)부터 적용

SwimFlow(이하 "본 앱")는 unnest(이하 "개발자")가 제공하는 수영 세션 설계 앱입니다.

1. 앱에서 사용하는 정보

허용한 수영 기록·거리·스트로크 수·심박수·활동 에너지를 Apple 건강에서 읽어 분석과 세션 추천에 사용합니다. iPhone 앱은 건강 기록을 수정하거나 삭제하지 않습니다.

Apple Watch는 운동 측정을 위해 위 수영 정보를 읽고, 진행한 운동의 기록·거리·활동 에너지를 Apple 건강에 저장합니다.

입력한 수영 경력·빈도·주 영법·페이스·수영장 길이, 세션·템플릿·Watch 표시 설정은 기기에 저장합니다. 선택 입력한 출생 연도는 추정 최대 심박수 계산에 사용합니다. 세션 진행에 필요한 정보는 페어링된 iPhone과 Watch 사이에 전달됩니다.

2. 제품 개선을 위한 사용 통계

iPhone에서 사용 통계 수집·이용과 국외 이전에 모두 동의한 경우에만 제품 개선을 위해 TelemetryDeck에 다음 정보를 전송합니다. 선택하지 않거나 거절해도 모든 기능을 사용할 수 있습니다. Watch 앱은 사용 통계를 수집하지 않습니다.

운동 완료 사실·수영 기록·운동 수치·심박수·수면 정보는 사용 통계로 전송하지 않습니다. 출생 연도·템플릿 이름·문의 메일 내용도 통계에 포함되지 않습니다.

설정 > 사용 통계 공유에서 언제든 끌 수 있습니다. 끄면 이후 전송과 대기 이벤트의 전송을 중단합니다. 건강 권한과 통계 동의는 별개이며, 건강 데이터를 광고에 이용하거나 판매하지 않습니다.

통계 분석을 위해 다음과 같이 국외 처리·보관을 맡깁니다. 근거는 이용자의 별도 선택 동의입니다.

3. 웹사이트와 문의 메일

웹사이트 제공자인 GitHub Pages는 보안을 위해 방문 IP를 기록합니다. 본 앱의 개발자는 웹사이트에 별도 광고·방문 분석 도구를 사용하지 않습니다. GitHub 개인정보처리방침

지원 메일의 발신 주소·문의 내용·첨부파일은 답변과 문제 해결에 사용하며 Gmail로 수신합니다. Google 개인정보처리방침

외부 서비스가 자체적으로 처리하는 정보에는 각 제공자의 개인정보처리방침이 적용됩니다.

4. 보관과 삭제

  • 기기 데이터: 앱을 삭제하면 해당 기기의 앱 데이터가 삭제됩니다. ‘앱 정리하기’, 다른 기기의 데이터, Apple의 백업·동기화는 별개입니다.
  • 건강 기록: 앱 삭제 후에도 Apple 건강에 남으며, 기록과 접근 권한은 건강 앱에서 관리할 수 있습니다. 권한 관리 안내
  • 사용 통계: 이미 전송된 정보의 보관·삭제는 TelemetryDeck 정책을 따릅니다. 공유 끄기나 앱 삭제는 기존 전송 정보의 삭제를 뜻하지 않습니다.
  • 문의 메일: 문의 종료 후 최대 90일 보관 후 삭제합니다.

5. 문의와 권리 행사

정보의 열람·정정·삭제·처리정지 요청은 아래 주소로 보내 주세요. 요청 대상과 처리 가능 범위를 확인해 안내합니다. 통계는 운영자가 특정 사용자의 전송 기록을 찾아 삭제하기 어려우며, 이후 전송 중단은 앱 설정에서 직접 할 수 있습니다. 문의에 불필요한 건강 기록이나 다른 사람의 개인정보는 첨부하지 않아도 됩니다.
